# $R_n=\star2$ and $Qo_n=\star3$ for every odd $n\ge 11$ (whole-board game): proof note

**Summary**
1. Theorem: in the whole-board game on $C_n$ (race rule "count", e.p. on, an e.p.-capturable pawn is not passed, the game ends at the first passed pawn), for every odd $n\ge11$ the $(n+2)$-pawn positions $R_n=$ W5 B7 (W2 B4)$^{(n-9)/2}$ W2 W3B6 W3 W2B5 B5 W2 B4 and $Qo_n$ (W4 for W5) are $\star2$ resp. $\star3$ (meaning: H7); both fail at $n=9$ (LLLL).
2. The proof is T50's insertion proof (`research/ring_family_proof/proof.tex`, Lemmas 1-3, with the repaired "pattern file" and the written-out Lemma 3 of `PROOF.md` 2b), at ONE fixed cut $c=6$ and ONE base $n_0=19$ for both families. The wall (files $2..n-7$) has odd length $n-8$ and W2 at both ends; neither end enters the lemmas (H1, H3).
3. C1: the reduced games at $n_0=19$ have 429 ($R$) and 1287 ($Qo$) nodes, no e.p. flag, no passed pawn, zone $\{n-7..n-3,n-1\}$ (for $Qo$ also $\{0,1\}$), signature NNPN resp. NNNP; files $2..11$ are exact pattern files in every node, and $R_{n+2}=\mathrm{ins}_6(R_n)$ was verified for $19\to21,\dots,57\to59$ (A) and, by independent programs, for $19\to21,\dots,31\to33$. C2: $n=11,13,15,17$ by direct search. E.p. convention: a flag is recorded only if an enemy pawn stands beside the landing square (section 1).
4. Status: PROVED [AI] for odd $n\ge19$ given T50's Lemmas 1-3, 2b and C1; CHECKED-2 for $n=11..17$ (finite checks by 5-6 programs each, section 7). By AI models only: two adversarial Claude verifier lenses (section 7) found no mathematical defect (the fixes are wording, convention and labels), but this note has no non-Claude referee yet (the lemma text it relies on, PROOF.md 2b, was refereed by Codex in T53; PROOF_Q.md by Codex in T62).
5. Scope: whole-board game, race rule "count" only (not cylcgt's component-sum model, not the rules "mover"/"opponent"), odd $n\ge11$; $n=9$ is false.

## 1. Setting
Model, classes T/L/P/K, reduced game: as in `proof.tex` and PROOF.md section 1 (race rule "count"). **E.p. convention** (as in `proof.tex`, Model): an e.p. flag is recorded only if an enemy pawn stands beside the landing square of the double step; a flag nobody could use is dropped. "No flag" in C1, H4, H6 and Lemmas 2-3 means this canonical convention. A, C, D, E, O use it, and B applies it through `difftest.norm_ep`; `cylcgt/pawns.py` itself records a flag after every double step, but its `ep_capturable` and `moves` act on a flag only when an enemy pawn stands beside the square, so an inert flag changes nothing but the name of the position. This was checked: with raw flags the reduced graphs have 434 ($R$) and 1302 ($Qo$) nodes for every odd $n=11..25$ (5 resp. 15 nodes carry an inert flag; 231 and 639 at $n=9$), and dropping the inert flags gives exactly the canonical graph, edge for edge, with the same signature (O, `verify_computeOdd/logs/b_reduced.txt`; also rebuilt by the integrator (the session that wrote section 7) directly on `pawns.moves/passed/_child` at $n=19$: 434 nodes, 5 inert flags, node and edge sets equal to the canonical ones, 1100 raw vs 1082 canonical edges; likewise 1302, 15, 3886 vs 3827 for $Qo_{19}$). Files $0..n-1$, $n$ odd $\ge11$:
file 0 W5 ($R$) or W4 ($Qo$); file 1 B7; file $j$ ($2\le j\le n-7$) W2 if $j$ is even, B4 if $j$ is odd; then W3B6 ($n-6$), W3 ($n-5$), W2B5 ($n-4$), B5 ($n-3$), W2 ($n-2$), B4 ($n-1$).
That is $2+(n-8)+8=n+2$ pawns. The **wall** is files $2..n-7$: type E (black pawn two ranks above the white one), length $n-8$ (odd), W2 on file 2 (beside B7) and on file $n-7$ (beside W3B6). **Pattern file** (PROOF.md section 2): a wall file whose content is exactly its start pawn. $\mathrm{ins}_c$ as in Lemma 3. $R_n$ ($Qo_n$) also denotes the reduced game, $\mathrm{start}_n$ its root. $Z_n=\{n-7,\dots,n-3,n-1\}$ ($R$), $\{0,1\}\cup\{n-7,\dots,n-3,n-1\}$ ($Qo$).
Lemma 1: a side wins $G+\star h$ moving first iff it wins the reduced game moving first. Lemma 2: for a wall pawn $q$ of the player $Z$ to move with pattern neighbour files, (a) $Z$ has no passed pawn after any move of $q$, (b) if $c$ has no flag and the window $j-1..j+3$ (or $j-3..j+1$) consists of pattern files, every move of $q$ is L or P. Lemma 3: if $p$ has no passer, no flag, and files $c-4..c+5$ are pattern files, then the K-children and the existence of T-moves of $\mathrm{ins}_c(p)$ are the $\mathrm{ins}_c$-images of those of $p$.

## 2. The cut and the base
Zone and pattern files. By C1, in every node of the reduced game of $G_n$ ($n\ge19$) all files outside $Z_n$ keep their start content. So files $2..n-8$ are pattern files of every node. The arc $A=\{c-4..c+5\}$ lies in $[2,n-8]$ iff $6\le c\le n-13$; the least $n$ is $n_0=19$, where $c=6$ is the only cut (`pump_verify.py` finds $c=6$ automatically at $19\to21$), and $c=6$ is admissible for every $n\ge19$. $A=\{2..11\}$ never wraps: the outside $12..n-1,0,1$ is one cyclic arc, which contains $Z_n$ and the files 0, 1 (not touched by $\mathrm{ins}_6$). $\mathrm{ins}_6$ fixes files $0..6$ and shifts files $\ge7$ by 2, so $\mathrm{ins}_6(Z_n)=Z_{n+2}$. The range $6\le c\le n-13$ is what Lemma 3's arc hypothesis needs, so it is sufficient, not necessary: the computation shows that $\mathrm{ins}_c:G_n\to G_{n+2}$ is an isomorphism of the reduced graphs for every $c=2..n-9$ (O, $n=19..31$), and for $n=11..17$ at some cuts (only $c=2$ at $n=11$; $c=2..8$ at $n=17$; `iso_small.txt`). So the graphs for $n<19$ are also $\mathrm{ins}$-images of each other, but they do not satisfy Lemma 3's hypothesis (no ten-file arc of unchanged wall files) and are covered by C2, not by the induction.

## 3. Hypotheses of Lemmas 2 and 3
**H1 (wall, phase, ends).** The wall alternates W2 (even) / B4 (odd). $\mathrm{ins}_6$ inserts copies of file 7 (B4) and file 6 (W2) after file 6, so the new files 7, 8 continue the phase; $\mathrm{ins}_6(\mathrm{start}_n)=\mathrm{start}_{n+2}$ for $n\ge14$ (files 6, 7 are wall files), which covers $n\ge19$. The phase and ends differ from $E_n$, $P_n$, $Q_n$ (here W2 at both ends), but Lemma 2(b) uses only the rows W2$\to$3, W2$\to$4 (e.p.) and B4$\to$3 of T50's table, and Lemma 3 only the views of pawns (PROOF.md H2, 2b); neither uses a file's parity or a wall end.
**H2 (no capture by $q$).** With pattern neighbours the capture squares of $q$ on rank 3 are empty, and B4 cannot take e.p. a W2 that has not moved (PROOF.md H3).
**H3 (windows at the two ends of the arc).** Central pawns: files $c-3..c+4=3..10$ of $p$, and $3..12$ of $\hat p=\mathrm{ins}_6(p)$ (arc $2..13$). Window of $q$ on file $j$: $j-1..j+3$ if $j\le c+2$ (resp. $c+4$ in $\hat p$), else $j-3..j+1$; all lie in the arc. *Left end:* $j=3$, $q=$B4, window $2..6$ (file 2 is the first wall file, W2 beside B7 on file 1; files 0, 1 are in no window): after B4$\to$3 the W2 on file 4 takes on $(3,3)$ and is passed (files $2,3,4$ then hold no black pawn), the black B4 on file 5 stays blocked by W2 on file 6. *Right end:* $j=10$ in $p$ ($j=12$ in $\hat p$), $q=$W2, window $7..11$ ($9..13$): after W2$\to$3, resp. $\to$4, B4 on $j-1$ takes (e.p. after $\to$4); the W2 on $j-2$ stays blocked by B4 on $j-3$. The window ends at file $11=n_0-8$ (resp. 13), so the wall-end file $n-7$ (W2, inside $Z_n$) is never part of a window. In 18 of 429 ($R$), 54 of 1287 ($Qo$) nodes the double step of $q$ on file 10 is L, not P: the W2 on file 12 has left, so B4 on file 11 is passed, the "$Y$ has a passer" branch of Lemma 2(b); the proof needs only that central moves are neither T nor K, so nothing breaks (as in PROOF.md H2, end case).
**H4 (start).** $\mathrm{start}_n$ has no passed pawn and no flag: W5/W4 (0) is blocked by B7 (1), B7 by W5/W4; a wall W2 by the B4 on an adjacent file (file 2: B4 on 3; file $n-7$: B4 on $n-8$), a wall B4 on file $j$ by W2 on $j-1$; W3B6 (file $n-6$): each blocks the other; W3 ($n-5$) by B6; W2B5 ($n-4$): each blocks the other; B5 ($n-3$) by W2 ($n-4$); W2 ($n-2$) by B5; B4 ($n-1$) by W2 ($n-2$). E ran the passed-pawn test on all nodes: none has a passer.
**H5 (race rule).** Lemma 2 never uses the race; in Lemma 3 the passed pawns of $c_\mu$ and $\mathrm{ins}_6(c_\mu)$ coincide (V3), so any rule that depends on the passed pawns and on who moved gives the same class (PROOF.md H4). The value is rule-specific, the lemmas are not.
**H6 (invariant).** $I_n$: no node of the reduced game has a flag, and every node agrees with $\mathrm{start}_n$ outside $Z_n$. $I_{19}$ is C1. If $I_n$ holds ($n\ge19$): every node is non-terminal with no flag, and $A$ consists of pattern files (section 2), so Lemma 3 applies to every node with $c=6$; with H4 and induction on the distance from the root, nodes, K-edges and T-flags of $R_{n+2}$ are the $\mathrm{ins}_6$-images of those of $R_n$. An image has no flag; it agrees with $\mathrm{start}_{n+2}$ outside $Z_{n+2}$ since files 7, 8 are copies of pattern files 7, 6 and $\mathrm{ins}_6(Z_n)=Z_{n+2}$. So $I_{n+2}$.
**H7 (meaning of $=\star k$; heaps).** As in T50 and PROOF.md H8: $G=\star k$ means that for every heap $\star h$, $h<256$ (a passed pawn is worth $\pm256$), $G+\star h$ and $\star k+\star h$ have the same outcome, namely P for $h=k$ and N otherwise. It is the whole-board/heap-sum convention, not $G+X\equiv\star k+X$ for every game $X$. *R, $k=2$:* the signature of $R_n+\star h$ is N, N, P for $h=0,1,2$ (C1R); for every $h\ge3$, $R_n+\star h$ has the heap move to the P-position $R_n+\star2$, so it is N. *Qo, $k=3$:* N, N, N, P for $h=0..3$; for $h\ge4$ the move to $Qo_n+\star3$ gives N. The start has no flag and neither do the reduced nodes, so the e.p. convention across a heap move is immaterial (E ran both readings "keep" and "expire": identical results, `base_cases.log`).

## 5. Proof of the Theorem
Let $n\ge19$ be odd. $I_{19}$ is C1; H6 gives $I_n$ for all odd $n\ge19$ and $R_n\cong R_{19}$, $Qo_n\cong Qo_{19}$ (nodes, K-edges, T-flags). By C1 and Lemma 1, $R_n+\star2$ and $Qo_n+\star3$ are P-positions, and the signatures are NNP.. resp. NNNP.. as in C1; H7 gives all heaps: $R_n=\star2$, $Qo_n=\star3$. For $n=11,13,15,17$ use C2 and H7 (the same heap step). $\blacksquare$ (T19: PROVED [AI] given L1-L3, C1; T: with C2.)

## 6. Gaps and caveats
1. **No gap found in the hypotheses.** What is new relative to PROOF.md and PROOF_Q.md is only the wall's phase and ends (W2 at both ends, odd length), the cut $c=6$ at the left end of the pattern run (the window of the pawn on file 3 starts at the first wall file 2, beside B7) and $n_0=19$; H1-H3 treat each. The one point to look at is the window of the pawn on file 3: it needs only that file 2 is a pattern file, which holds in every node (file 2 is outside $Z_n$ and its W2 never moves in the reduced game: its 2 moves per node are P in all nodes, C1 information). The logic verifier of section 7 re-derived by hand every point where the odd configuration differs from the even cases (left end $j=3$ with window $2..6$, right end $j=10$ in $p$ and $j=12$ in $\hat p$ with the e.p. double step, odd wall length, W2 at both ends, the zones touching the arc, e.p. and race handling) and changed no step; the compute verifier recomputed the facts these arguments cite (zones, windows, tallies, pump).
