2.2 Order tests (definition and results; src/order55.py, logs/order.txt).
  Definition used.  LOOPY §3 has no order relation on loopy D-games.  The nearest definitions are in Proposition 3.9′
  ("y equals a number x (that is, y − x is a second-player win: both players lose moving first)") and in the conventions of
  "Sums with loopy components" ("Left wins G + n second" = (G + n, Right to move) ∈ W_L); Proposition 4.5's proof of
  0 < over < x uses the same difference game.  So we used the difference test in the D-sum:
     G >= H  iff White survives Z_O ⊞ (-H) with Black to move first;   G <= H iff Black survives it with White to move first;
  "survives" counted twice: draws for Left (White survives = W or D) and draws for Right (White must win, W).  -H is the
  negative (Left and Right swapped, ⊕ and ⊖ swapped).  Both counts gave the same answer in every case below (none of the
  deciding results was a draw).
  Results (W/L = White/Black wins; (White first, Black first) of Z_O ⊞ (-H)):
     H                 root A                            root B
     0                 (W, W): A > 0                     (W, W): B > 0
     ↑                 (L, L): A < ↑                     (W, L): B || ↑ (confused)
     ⇑*                (L, L): A < ⇑*                    (L, L): B < ⇑*
     over              (L, L): A < over                  (L, L): B < over
     tiny-n, n = 2, 4, 5, 12, 20, 30   (L, L): A < tiny-n   (W, L): B || tiny-n
     B_n, n = 5, 12, 20                (L, L): A < B_n      (L, L): B < B_n
     tA, tB            (L, L): A < tA, A < tB            tA: (W, L) confused;  tB: (L, L) B < tB
     tD, uD            (W, W): A > tD; uD: (W, L)        (W, W): B > tD, B > uD
  These are D-sum outcomes (CHECKED-2: za = rz).  They are not an order: for loopy or D-games the difference test is not even
  reflexive here.  tA ⊞ (-tA) is a draw with either side first (so "tA = tA" holds only with draws counted for the survivor),
  and tD ⊞ (-tD) with Black first is a Black win (Black's threat ⊖ comes one move before White's ⊕), so "tD >= tD" fails.
  Hence "A > tD" and "A < tA" say nothing about equality or about A's place between tD and tA.
2.3 Stopper.  Z_O is NOT a stopper (CHECKED by rz's stopper mode, COMPUTED-1; also by hand).  By hand: root A with Black to
  move, ...Kd4-d5 Kf5-f6 ...Kd5-d4 Kf6-f5 returns to it (every move legal: f6, f5 are not attacked, the kings stay two files
  apart), an alternating cycle of length 4.  By program (LOOPY §3 definition: the graph on (node, mover) with alternating moves
  has a cycle): 5,513,626 legal (node, mover) states, 5,512,994 of them start an infinite alternating line, all four root
  states included; a printed 16-cycle runs both kings round rank 1 (logs/stop_G8.out).  G9, G10, H10 are not stoppers either.
  What this means for 2.2: (i) Siegel's simplest forms, which LOOPY §3 ("Reading") uses for stoppers, are not available;
  (ii) Proposition 3.10 (no draws beside a stopper) does not apply, and draws do occur (beside over, under, on, dud);
  (iii) for non-stoppers G - G need not be a second-player win (on + off = dud), so the difference test is not a test of
  order or of equality; it is reported above as a list of D-sum outcomes only.  Z_O also has terminals (promotions), so
  the CGT translation of Theorem 3.7 needs first-event dominance, which was not checked.
2.4 Labels and what a battery can prove.  No candidate passed every test, so no COMPUTED-1 value is claimed.  The 2 + 3 group
  H10 passes every test against over (752 games, CHECKED-2); in the brief's terms this is a COMPUTED-1/CHECKED-2 signature,
  not a value.  A finite battery and an order test against one game do not prove equality: equality in D-sums means equal
  results in every context, and LOOPY §3 has no theorem that reduces this to finitely many tests or to the difference game.
  The nearest statements (Theorem 3.7 and the "Reading" after Theorem 3.8) identify a sum's D-result with a CGT outcome under
  first-event dominance and point to Siegel's theory for stoppers; Z_O and H10 are not stoppers, so neither applies.
